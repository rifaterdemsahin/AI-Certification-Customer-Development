## 2. Key Discussion Points & Verbatim Observations

### 1. Practical Applications & Agent Workflows (Presenter 1)
- **Goal & Alignment:** Before building agents, teams must ensure complete clarity and alignment on processes, costs, inputs, and outputs using structured frameworks like **HOPIS diagrams**.
- **Cost Controls:** API token consumption and LLM tool costs (e.g. Microsoft Copilot Studio, Claude, OpenAI APIs) can ramp up rapidly during design, prompt iteration, and agentic testing. Proper scoping upfront prevents runaway enterprise expenses.
- **No-Code / Enterprise Use Cases:** Demonstrating agent building (e.g., automating training contract generation, demand forecasting, claims triage) using platforms like **Microsoft Copilot Studio**, catering to non-technical business units while exposing clean APIs for developer extensions.

### 2. The B-MAD Framework & Enterprise AI Trends (Erdem)
- **Shift to Multi-Agent Systems:** Enterprise AI has moved past single-chat conversational assistants into **multi-agent architectures**. Utilizing techniques like **context sharding** allows complex, multi-step enterprise workflows to execute without context window overflow or state degradation.
- **B-MAD (Breakthrough Method for Agile Delivery):** An evolution of Agile/Scrum specifically tailored for AI agent development. Integrates role-based autonomous workflows (analysts, architects, developers, testers) alongside concrete certification and skill validation tracks.
- **Accuracy & Hallucination Suppression:** Multi-agent orchestration with dedicated critic/verification agents reduces hallucination and revision rates down significantly from the ~75% failure rate typical in naive single-agent prompt pipelines.

### 3. Organizational Strategy & Compliance (Client Team)
- **Insurance Sector Constraints:** Due to strict insurance regulations, customer data isolation, and competitive compliance, cross-organizational data sharing must be strictly restricted. Certain generalized features must remain siloed or partitioned strictly for public-good / non-proprietary initiatives.
- **Training Program Structure:**
  - **Track 1 (Business Units):** Non-technical & executive alignment on agent capabilities, ROI discovery, HOPIS process mapping, and prompt governance (delivered **online**).
  - **Track 2 (Technical Teams):** Hands-on architecture, code scaffolding, multi-agent context sharding, and agent deployment (delivered **in-person**).
  - **Specialized Deep-Dive Workshops:** Targeted modules for **Monitoring & Observability Teams** (agent telemetry, cost tracking, drift detection) and **RAG (Retrieval-Augmented Generation) & Fine-Tuning** for secure on-premise/hybrid private cloud environments.
