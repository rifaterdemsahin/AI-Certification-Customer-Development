# Skool 2-Hour Workshop Upload Sanity Check — v1.0

**Date:** 2026-08-13  
**Author context:** Founder (Rifat Erdem Sahin) already runs a fixed Sunday 9–11pm live cohort and has configured 7 Skool classrooms. Question: should the 2-hour recordings be uploaded into Skool?  
**Linked site page:** `5_Symbols/product/skool-workshop-upload.html`

---

## Verdict

**Yes — upload the 2-hour Sunday recording into Skool Classroom the same night, as the replay archive of the live room. Do not treat the raw file as the course. Do not put it on public YouTube.**

| Move | Verdict | Why |
|---|---|---|
| Upload 2-hour replay to Skool Classroom | ✅ **Do** | Redeems H5 Premise 3 ($10/mo = recorded replays). Serves missed Sundays. Reuses the one live slot. |
| Add 5–8 timestamps | ✅ **Do** | Only edit a second-job founder can afford. Time-poor members jump. |
| Cut one 60–180s highlight for YouTube / LinkedIn | ✅ **Do** | Acquisition stays outside Skool. Already on `content-format.html`. |
| Native Skool host | ✅ **Do (default)** | Student screens stay inside the paid room. |
| Unlisted YouTube embed into Skool | ⚠️ **Only if** native upload fails **and** no student screens | Unlisted still leaks. |
| Public YouTube of the full 2 hours | 🚫 **Never** | Gives away the paid room; exposes attendees; skips the H5 pay-to-be-live test. |
| Recut 2 hours into a polished course | 🚫 **Never at Stage 2** | Editor hire is H11 / ~$100k ARR. Animate the 8–25 min lesson separately. |
| Count replay % viewed toward H10 | 🚫 **Never** | H10 is the YouTube *guide* catalog. Live dead-air would falsify it. |

---

## What this is not

This is not a re-open of “should workshops live on Skool?” That is already decided:

1. `content-format.html` — workshops’ primary home is Skool (calendar + live + Classroom replay). YouTube gets the highlight reel only.
2. `skool-lms-integration.html` — Stage 2 row: “Host recorded replays in Classroom.”
3. `youtube-skool-handoff.html` — YouTube / LinkedIn acquire; Skool delivers.
4. H5 Premise 3 — $10/mo includes recorded replays; $250 / $500 buy the live screen-share seat.

The new question is only: **is the uncut 2-hour file a legitimate Classroom asset, or should it be recut / withheld / posted publicly?**

---

## Why uploading is correct

1. **The cheap tier is empty without it.** H5 P3 already sold $10/mo as async replay access. If the file never lands, that SKU has nothing to redeem.
2. **Missed Sunday is the default.** Brian’s discovery feedback (H5) is time constraint, not lack of interest. One founder cannot add a second live slot (`single-founder-bandwidth.html`).
3. **Upload is ~20 minutes; recutting is hours.** Same-night native upload + timestamps fits after 11pm. Recutting steals weekday evenings from the animated lessons that feed H7 search.
4. **Privacy.** Sunday is a screen-share room. Public YouTube would leak terminals and skip the test of whether people will pay to be live (H5).

---

## Why a raw dump is incomplete

1. **H2 / H10 will look failed if you score these files.** The only measured retention number is a 68.5% *animated short* (H2). A 2-hour live recording will not clear H10’s >40% catalog floor and must be excluded from that catalog.
2. **Nobody watches 2 hours async in a 2–3 week exam window** (H21 Premise 4). Timestamps are the mitigation, not a recut.
3. **Seven classrooms of blobs ≠ curriculum.** H8 Premise 1 needs finishable scope. The 8–25 min animated lesson + files + H27 question bank are the module. The replay is the appendix.
4. **Skool playback is “standard”** (`skool-vs-youtube.html`). Fine for a private archive. Not a reason to move long *public* teaching off YouTube.

---

## Same-night ritual (~20 minutes)

1. Stop recording. Save the Sunday 9–11pm file as-is.
2. Upload native into the matching Classroom of the 7.
3. Write 5–8 timestamps (setup / build / debug / recap).
4. Cut one 60–180s highlight for YouTube + native LinkedIn. One board line: “Replay is in Classroom N.”

If this block grows past 30 minutes, you are editing. Stop.

Mid-week still belongs to `cohort-prep.html` (install list + preview, dual-posted). Production order for the *taught* lesson stays: animate the long → cut the Short → file in Classroom → workshop it Sunday.

---

## What each tier buys (unchanged, now operational)

| Tier | Gets the 2-hour replay? | Also gets |
|---|---|---|
| $10/mo | Yes (this is the asset) | Forum, Classroom files |
| $29 bundle (H21) | No | Memory cards + mock + prep exam |
| $250 / $500 | Yes, plus the live Sunday seat and screen-share | Everything in $10/mo |

Replay does not cannibalize the live seat if live value is real-time debug + accountability (H8 Premise 2). If live attendance dies after replays exist, that is a useful H8 signal — not a reason to withhold the archive from $10/mo.

---

## What this does / does not validate

- **H5** — Premise 3 becomes a real asset. Paid enrollments still required to move status.
- **H8** — A replay library is not PMF.
- **H2 / H10** — Do not score these files against the >40% guide-retention floor.
- **H27** — Question-bank production still outranks another replay as the conversion asset.
- **H9** — Hours of uploaded video do not clear $10,000. Two consecutive paid launches do.
