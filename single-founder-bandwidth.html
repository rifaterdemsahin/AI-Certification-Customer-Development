🧑‍💻 Single-Founder Bandwidth

Acidity check Finding F3: production, curriculum, and teaching all run through one person with no bus-factor mitigation. This page makes the founder's actual weekly time ledger explicit, so the bandwidth ceiling is a known number instead of an assumed one.

The H3 newsletter (LinkedIn + YouTube) is now built and automated via n8n, which keeps the recurring weekly send itself off this manual time ledger.

📉 The Bandwidth Ceiling

Every hour spent on this project competes with rest, not with contracting income directly — but it's still finite. There is exactly one live delivery slot a week (Sunday 9–11pm), which caps how many cohort seats can be sold, how much 1-on-1 feedback can be given per student (see Unit Economics), and how many discovery interviews can be run per week, until either the slot count increases or a second person is involved in delivery.

🛟 Mitigations in Progress

🏫 Onsite Cambridge pilot
Testing an in-person delivery format alongside the online Sunday cohort — not a bandwidth fix by itself, but a signal-generating experiment on whether in-person delivery justifies eventually bringing in outside help. See Risk Analysis.
🤝 Corporate onsite pilot with Marianna
A named delivery partner on the corporate/B2B onsite pilot (H12, H17) is the first concrete step away from 100% solo delivery, even before the $100k ARR hiring trigger (H11). Note: before any expansion into additional onsite geographies (UK/Europe/USA — see H18 on Customer Creation), the same one-founder bandwidth limit applies — expansion is deliberately gated on a confidence score from the single UK pilot first, not run in parallel across countries.
💰 $100k ARR hiring trigger (structural fix, not yet reached)
The freelance editor, cohort coordinator, and technical TAs (see Company Building) are the real long-term bandwidth relief — but they're gated behind revenue this project hasn't hit yet.
🎯 Single-niche focus
Staying scoped to one certification (see Focus) is itself a bandwidth decision — it's what makes a one-person production and delivery schedule survivable at all right now.
🤖 n8n-automated newsletter (new, 2026-08-05)
The H3 LinkedIn + YouTube newsletter is now built and automated via n8n, so the recurring weekly send doesn't compete for founder time the way a manual send would — a small but real bandwidth win ahead of the bigger $100k ARR hiring trigger. See Task List.
