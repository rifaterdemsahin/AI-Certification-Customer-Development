⏱️ The Real Cost: Founder Time

Content production, live cohort delivery, and 1-on-1 feedback all run through one person, valued against his £525/day inside-IR35 contracting rate (see Unit Economics for the hourly breakdown, and Single-Founder Bandwidth for the weekly time ledger this is built on).

📌 This is opportunity cost, not lost income
Because content/cohort work happens in contract-free evening and weekend hours, it isn't directly displacing paid contracting time. It is still a real cost in foregone rest and personal time, and becomes an actual lost-income cost whenever weekend contract extension work is available and turned down in favor of this project.
⛔ £100k pure-time ceiling (H33)
Founder-decided stop-loss: four courses at £10k institutional value each (£40,000) plus £60,000 of founder time (≈ 114 days at £525/day). If that £100,000 GBP is spent and Discovery still cannot become Validation with Skool charging back paid seats, pivot. This is not the $100,000 USD ARR hire (H11). See £100k Pure-Time Pivot.

⚖️ Break-Even Math

Membership vs. Software/AI Fixed Cost

$115/month software stack (AI + Canva) ÷ $10/mo per member = 12 active members needed to cover software toolchains outright.

VIP Cohort vs. Operating Fixed Cost Stack

3 × $250 VIP cohort seats ($750) covers the entire monthly cash stack (£500 CB4 storage + AI multi-agent inference + Canva Pro) for that month.
