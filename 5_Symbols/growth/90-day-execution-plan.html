🗓️ 90-Day Execution Plan

2026-08-09 → 2026-11-07 (90 days, 13 Sunday cohort sessions). This page turns H19's stage-level estimates and Test Plan's open experiment queue into a single dated, day-1-to-day-90 execution sequence, built strictly inside the ceiling documented on Single-Founder Bandwidth: one live delivery slot a week (Sunday 9–11pm) plus evening/weekend production time. Day 1 of this plan lands on a Sunday, so it opens with a live cohort session rather than a cold start. Nothing below is a promise — it is a founder-set execution target, exactly as revisable as the H19 estimates it operationalizes.

🎯 90-Day Objective

📊 Instrument the funnel
Turn Test Plan item 2 (⚪ Not started) into real view→CTR→newsletter→cohort numbers, closing out H7's open targets.
🎬 Sustain 3 videos/week
Hold the production baseline set 2026-08-04 (Task List) for the full 90 days — roughly 38–39 new animated shorts, feeding H4 top-of-funnel volume.
🔍 Push toward Discovery exit
Measured newsletter conversion rate (H3) and catalog-wide retention data (H2), the two conditions H19 lists for the ~Q4 2026 Discovery exit — this window ends right at the start of that quarter.
🚪 Reach a Cohort Launch #1 go/no-go
Build the pre-launch waitlist signal Validation Repeat Gate requires, then decide — not commit in advance — whether to launch the first paid cohort (H5) inside or just after this window.

📅 Phase Breakdown

Phase Dates Focus Exit checkpoint
1. Foundation & Instrumentation Days 1–30
Aug 9 – Sep 7		 5 Sunday cohorts run as usual; funnel instrumentation goes live; LinkedIn Newsletter traffic routed and logged (H7); per-video subscriber counts start being logged (H13 baseline). Day 30: first real CTR/conversion numbers exist, even if far from target.
2. Waitlist & Discovery Exit Push Days 31–60
Sep 8 – Oct 7		 4 Sunday cohorts build the pre-launch waitlist; 30-day funnel numbers reviewed against H7's 10% CTR / 2% conversion targets; Cohort Launch #1 pricing/logistics prepped without a committed date. Day 60: waitlist size known, funnel numbers trending toward or away from H7 targets.
3. Launch Readiness Decision Days 61–90
Oct 8 – Nov 7		 4 Sunday cohorts; go/no-go call on Cohort Launch #1 using the waitlist + funnel data gathered in Phase 2; if "go," launch runs inside this phase, if "no," the gap is documented and folded back into a revised H19 estimate. Day 90: either a live paid cohort has launched (H5), or a documented reason it didn't.
