⚖️ Strategic Paradigm Shift: Ad-Hoc Sessions vs. Bi-Weekly Event Machine

❌ The Ad-Hoc / Impromptu Failure Mode

  • Fragmented Scheduling: Holding calls with only 1–2 days' notice causes high drop-off because busy engineering professionals cannot adjust calendars.
  • Invisible Attendance: Direct Zoom/Meet links hide attendee lists, generating zero social proof or network virality.
  • Single Platform Silo: Relying solely on internal WhatsApp or Skool messages leaves top-of-funnel discovery starved of net-new engineering talent.
  • Passive Consumption: Attendees leave without clear workplace deliverables or structured CRM follow-up, bleeding potential VIP and contractor leads.

✅ The Bi-Weekly Event & CRM Engine (Marianna Blueprint)

  • 14-Day Predictable Runway: Exactly 1 flagship workshop every 2 weeks, published 14 days in advance so working engineers can reserve the slot.
  • LinkedIn Events Viral Proof: Public attendee RSVPs trigger network feed notifications, creating viral popularization across second-degree engineering connections.
  • Free Multi-Channel Syndication: Automatic cross-listing across LinkedIn Events, Meetup, Eventbrite, and Luma with zero paid ad spend.
  • Active CRM Pipeline: Every registrant is tracked through a structured qualification funnel, converting attendees into toolchain users and VIP contractors.

🏗️ Standardized 8-Part Pedagogical Class Architecture

Marianna mandated that every event announcement and curriculum plan must follow a consistent, enterprise-grade pedagogical format to make value unmistakable and ensure immediate workplace applicability:

🏷️

1. Name & Session #

Clear semantic title indicating track and chronological stage (e.g., "Delivery Pilot Lab #12: Building Context-Aware MCP Servers").

📝

2. Real Problem Description

Concrete description of the real-world friction point encountered in enterprise environments (e.g., token overflow, knowledge fragmentation).

🎯

3. Concrete Session Goal

Specific, measurable objective targeted within the 60-minute sprint (e.g., deploy a local FastMCP server connected to Claude Desktop).

📦

4. Shipped Deliverables

Tangible codebase, configuration file, or architectural diagram created live and added to personal GitHub repositories.

⚡

5. Skills Mastered

Verifiable technical capabilities unlocked (e.g., Python FastMCP, JSON-RPC protocol, tool calling schema validation).

🧪

6. Hands-On Exercises

Live, interactive execution following the Anna 5-10-5 or 10-10-15 sprint model with real-time "Check & Help" verification.

💼

7. Monday Workplace ROI

Exact instructions on how attendees apply the newly built artifact at their corporate job or client contract on Monday morning.

📹

8. Recordings & Assets

Archived session replays, slide decks, and code starter repositories published on LinkedIn, Skool Classroom, and YouTube.

🚀 14-Day LinkedIn Event Viral Promotion Arc

The 3-Wave Social Promotion Timeline

Rather than posting a single announcement on the day of the call, every bi-weekly event executes a structured 3-wave marketing arc on LinkedIn:

DAY -14
Wave 1: Event Creation & Registration Launch

Create the official LinkedIn Event page with complete 8-part class blueprint. Send direct invites to 50+ targeted cloud/DevOps engineers. Post Announcement #1 focusing on the core architectural problem.

DAY -7
Wave 2: Practical Lab Spotlight & Network Sharing Ask

Publish Post #2 featuring a visual diagram or code snippet of the hands-on exercise. Tag existing founding regulars and ask attendees to click "Share" on the LinkedIn Event to invite their peers.

DAY -2
Wave 3: Final Call, 1-on-1 Direct Messages & Room Prep

Publish Post #3 with the final agenda and starter repository prerequisites. Send personal 1-1 WhatsApp/LinkedIn DMs to registered members confirming their attendance slot.

🌐 Multi-Platform Free Event Syndication Channels

To expand reach beyond existing LinkedIn followers, event listings are automatically cross-syndicated across top developer event aggregators:

💼 LinkedIn Events

Primary distribution engine. Shows public attendee lists, pushes push notifications to attendee connections, and integrates directly with founder profile and Delivery Pilot Organization page.

🤝 Meetup.com

Taps into local London and global online tech/AI meetup search queries. Attracts organic engineering talent searching for practical weekend and evening workshops.

🎟️ Eventbrite & Luma

Captures enterprise technology managers, testing leads, and AI researchers actively browsing professional development and corporate training listings.
