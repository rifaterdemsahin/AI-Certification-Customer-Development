🎡 The Funfair Token System

It works like a funfair 🎠: the audience earns 🎟️ time-based tokens for showing up, engaging, and bringing friends — then spends them inside the fair on the products that live there: 🗂️ Memory Cards, 📝 Mock Exams, and 💼 The Ultimate IT Contractor Course. Tokens expire on a clock — like a fair that packs up at night — so people who get a token feel the pull to use it now, not hoard it. This is an engagement & urgency tactic added to Marketing Tactics; the products it unlocks are the real SKUs tracked in H21 (see H21) and the Delivery Pilot ladder in H30 (see H30).

🎠 How The Fair Works

🎟️ 1. Earn At The Token Booth

Tokens are given for real engagement: attending the Sunday live room, commenting on community hubs, hitting watch-retention, bringing a new member in. Never for paying — paying is what the real ticket counter is for.

⏳ 2. The Clock Is Running

Every token is time-based: minted Sunday, expired next Sunday. A token that dies unspent is a nudge to come back — the weekly rhythm matches the founder's own Sunday cadence.

🎪 3. Spend At The Stalls

Tokens unlock the products inside the fair: memory card decks, mock exam attempts, and contractor-course modules. Same products that already exist as paid SKUs — tokens give a taste, the cash checkout gives the seat.

⏳ Time-Based Expiry — The Fair Packs Up Sunday Night

🕰️

7-Day Token Life

Minted Sunday 21:00 UK → expires next Sunday 20:59 UK.

  • 🏃Urgency without fake countdowns: the expiry is real and visible — a token dies, a new weekly batch arrives. Contrast with the banned fake-countdown pattern in Marketing Tactics.
  • 🔁Weekly return loop: expiry syncs to the Sunday live room — the one event the whole funnel already points at (see Delivery Pilot Offer).
  • 🧑‍💻Founder bandwidth-safe: tokens are settled in the same weekly batch cycle as YouTube/LinkedIn comments — no real-time token server needed at this stage.

🧭 Why Time-Based Tokens (Not Points)

⏱️ Expiry Creates The Visit
Loyalty points get hoarded; funfair tokens get spent because the fair closes. The weekly expiry converts "I'll come back someday" into "I'd better use these by Sunday."
🎁 A Taste, Not A Discount
Tokens unlock samples of products (a deck, an attempt, a module) — the same upsell shape as the Hormozi preview ramp on Delivery Pilot Offer. The full SKU stays a paid seat.
🎮 Rides The Existing Game Layer
Sits on top of the XP/leaderboard unlockables already scoped in Skool Offer Ideas — tokens are the currency, the stalls are the unlockables, the fair is the community.
📏 Every Earn Is Already Measured
Attendance, comments, referrals, retention — each earning action is already a logged signal in the Dual Scorecard (see Metrics Dashboard), so token issuance needs no new telemetry.

⚠️ Guardrails & Sanity Check

Open Questions:

  • All token values and stall prices are draft numbers — no issuance or redemption data exists yet. Marked as a test, not a shipped mechanic.
  • Where does the ledger live? Skool has no native token ledger — the lowest-friction v1 is a public weekly scoreboard post (founder-settled in the Sunday batch cycle), not custom code.

Key Risks:

  • Never devalue the cash SKUs: tokens sample products; the $29 bundle, $10/mo membership, and $250 VIP seat stay the real checkout (see H21, H5).
  • No fake urgency: expiry is a real weekly rule, not a countdown timer — consistent with the compliance rule on Marketing Tactics.
  • Anti-spam: tokens are granted only for founder-verified engagement, aligned with the Level 2 posting gate on Skool Posting Restriction.
