Continuous, non-deterministic agent runs incur substantial token costs — Hermes introduced as the future alternative for moving agents to local/deterministic setups to optimise budget.

🧭 Four Things the Session Settled

Delegation target: her own admin

Cost-per-run is part of the offer

Token spend was a headline caution; local/deterministic execution (Hermes) is the named budget fix; and the participant set the follow-up agenda on it. Dedicated QA agents double context cost — constrain the prompt and review flags instead.

The master record lives outside the platform

A centralised Google Sheet is the “second brain”, held independently so leads survive losing platform access. Second independent confirmation — the Amazon FBA operator asked for the governing “main brain” from the other direction. Settled rule, not an option.

Bounded autonomy, not mass sending

Human-in-the-loop review flags; ~20-minute gaps between dispatches; engagement only 07:00–19:00. Third independent instance of the approval boundary (with Chidi and Baran G) and zero instances of demand for unattended sending.
