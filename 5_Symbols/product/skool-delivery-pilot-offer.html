📌 How to position

Position Delivery Pilot as a Sunday problem-solving room you can preview — not a membership, not a Claude course, not a status ladder.

The product is proximity to the live screen. YouTube already teaches. Skool should let someone feel the room in under two minutes, sit in this Sunday for a dollar, then pay $250/year only when they want their architecture reviewed. Hormozi: raise the dream and the likelihood, crush time and effort. Blank: this is still a test (see H5) until someone pays for the live-share seat.

One sentence a stranger can repeat: “Every Sunday at 9pm we solve Claude Architect problems live. Peek free. Sit in for $1. Share your screen for $250/year.” We do not grant the certification (Anthropic does, via Pearson VUE). We run the practice room.

🏋️ Hormozi tactics on this page

Value Equation

Dream: walk into the Claude Architect exam having already solved the hard problems out loud.
Likelihood: 11 people already in the room, 8 recorded Sundays, live every week — and you can preview before $250.
Time: next Sunday, not a 12-week course you start someday.
Effort: show up; the midweek install list kills setup sacrifice (see Cohort Prep).

Stack the $250 receipt

Name the parts so $250 looks like theft, not a fee. Sunday live-share seat (~52 weeks) + founder review + full Classroom + all replays + install list + peer board. Do not compete with Udemy on price. Compete on “your screen, reviewed.” The agent page still wants a later Architect Exam Sprint at $497–$997 once the mock exists (H27). This week: stack first, take the first paid seat.

Magnet vs tripwire vs offer

Peek = lead magnet (free). Sit In = tripwire ($1 so they raise a hand). Share Screen = the offer. The $29 bundle stays a separate tripwire for people who only want mocks (H21) — do not put it on this Skool join page or you recreate the catalog the Hormozi agent already graded a C.

Process reverse, never a pass promise

Peek is free. Sit In cancels any month. Share Screen: attend two Sundays, if you did not get a live review, cancel and keep what you used. Anthropic still issues the badge. Site-wide rule: no exam-pass guarantee language. That is a process guarantee — it raises likelihood without lying.
