🔍 Why the node has no arrows

Three separate facts stack into the lonely circle. None of them mean H1 is unused.

1. The SVG only draws explicit Feeds

The live diagram on hypothesis.html draws a line only when HYPOTHESIS.md has a written Feeds citation. H1's own line is: Depends on: None — foundational premise. No upstream hypothesis is cited. There is no dep-H1 path in the SVG, so no filament leaves the node.

2. Downstream bets were written as peers

H3 (will they pay), H6 (how big), H8 (does the cohort work), H12 (will firms buy), and H14 (other certs) were each stated as their own foundational premise. They assume H1 is true in the narrative, but none of their Depends on lines name H1. The map records citations, not implied weather.

3. The one dashed edge is off-canvas

The mermaid in HYPOTHESIS.md has one related-to edge: H1 -.-> H25 (cert-value bifurcation is a refinement of rising skills demand). H25 is not drawn on the live SVG at all — that diagram still shows the original ~19-node set. The only written H1 edge is therefore invisible on the page you are looking at.
